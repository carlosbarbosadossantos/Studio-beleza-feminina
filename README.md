## Imagens

As imagens configuradas no `script.js` usam links externos de fotos públicas associadas ao Studio em listagens online. Para uma versão final de produção, o ideal é substituir esses links por arquivos originais fornecidos pelo próprio Studio e hospedá-los junto do site.

## Edição rápida

Os principais textos, cores, contatos, serviços e imagens ficam no objeto `CONFIG`, no início do arquivo `script.js`.

Abra `index.html` no navegador para visualizar. Para publicar, envie a pasta para Vercel, Netlify, GitHub Pages ou hospedagem equivalente.
